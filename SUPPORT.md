# Support

Use GitHub issues for reproducible problems with templates, skills, scripts, or documentation. Include the project version, operating system, command run, expected behavior, and sanitized output.

Improvement proposals should describe the repeated repository problem they solve. Agent Practices cannot provide support for a coding agent vendor, review private source code, or guarantee that a third-party tool automatically discovers these files.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md). Do not put credentials, private repository content, customer data, or undisclosed vulnerabilities in an issue.
