# Adoption reports

Real use should drive this project. An adoption report records what happened when Agent Practices was installed into a repository; it is not a testimonial.

Open an **Adoption report** issue after at least one real agent-assisted change. Share only public or sanitized information and include:

- repository type and chosen template;
- skills kept or removed;
- whether the agent discovered the contract without extra configuration;
- one instruction that changed the outcome;
- one confusing, redundant, or missing instruction;
- checks the agent actually ran.

Maintainers use recurring evidence to refine templates and skills. A single tool-specific failure may belong in compatibility documentation rather than a universal rule.
