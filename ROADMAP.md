# Roadmap

Agent Practices evolves through real repository use. Proposed work should solve a repeatable contributor or agent problem and remain useful across vendors.

## Near term

- Add tested examples from small application and library repositories
- Define a machine-readable catalog without making Markdown consumption harder
- Add Windows-friendly adoption instructions
- Validate links and shell examples in CI

## Exploring

- Nested guidance for monorepos
- Profiles for documentation-only and infrastructure repositories
- A compatibility test matrix for agent instruction discovery

Open an improvement proposal before starting a large roadmap item so the scope can be discussed.
